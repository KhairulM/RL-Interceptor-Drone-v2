## Methodology

- Percentile bootstrap CI over 3-5 seeds is anti-conservative (nominal 95 % covers 0 under the null 76 % at n = 3,
  86 % at n = 5). Affects every "CI excludes 0 = supported" claim. Open: user decision (t-interval / exact sign-flip).
- Independent noise draws for the observation and the estimator / oracle inputs of the same quantity (A3b/c/d, F4, F5):
  estimator arms see two noisy copies. Open, with #3.
- Paired "other campaigns' evaders" sets differ in size between arms (F6/F6b vs F3, F7, F8 roncero vs hedge). Footnote.
- A1b `gap_closed` uses the seed-0 baseline (X4 uses the M0 seed mean); only in A1b summary.md, not RESULTS.md.
